# 2–3 minute demo script

**Recording reminder:** keep your camera enabled during the recording, as required by the assignment. This is a script only; it does not mean a recording has been made or uploaded.

1. **Problem and product (20 seconds):** “Product and growth teams need a quick way to learn from a large interview library without relying on uncited AI claims. This assistant searches the transcript corpus and keeps source evidence attached.”
2. **Grounded chat (40 seconds):** ask a focused question that matches an indexed source, show the answer and source panel, then ask an unsupported question to show abstention.
3. **Local Ollama (25 seconds):** point to the selected `ollama · qwen2.5:3b` provider and the health indicators; explain that no paid API key is needed for the local path.
4. **Persistence and writing (35 seconds):** start a new chat, switch back to the prior session, then generate a topic-based Ship 30 essay and inspect its citations.
5. **Artifacts and trade-off (30 seconds):** generate an HTML/CSS artifact and show its isolated preview. Explain the trade-off: scripts/network are blocked for safety, so previews are static.
6. **Handoff (15 seconds):** point to README, startup scripts, migration/ingestion instructions, and the test report. Mention any unavailable Docker/model dependency candidly.
